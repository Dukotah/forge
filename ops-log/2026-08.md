**Why distinct from ada-compliance-checklist.html:**

These are what plaintiffs’ attorneys look for as evidence of good-faith remediation — not just knowledge of the issues, but documented action.

**Article structure (TechArticle + FAQPage JSON-LD, datePublished/dateModified: 2026-08-31):**

1. **Step 1: Fix template-level failures first** — `lang` attribute on `<html>`, skip navigation link, `<title>` uniqueness. These appear on every page; one template fix propagates everywhere. Fastest ROI for litigation risk reduction.
2. **Step 2: Fix all missing alt text** — batch audit with Axe DevTools; alt text writing rules (informational vs. decorative vs. linked images); verification with VoiceOver/NVDA spot-check.
3. **Step 3: Fix all unlabeled form inputs** — associate every `<input>`, `<select>`, `<textarea>` with a `<label>`; handle placeholder-only patterns; verify with click-the-label test.
4. **Step 4: Fix color contrast failures** — use WebAIM Contrast Checker; fix in CSS tokens so the change propagates; verify on live page after deploy.
5. **Step 5: Fix keyboard navigation** — Tab-only walkthrough; remove `outline:none` globally; test modal focus trapping (Escape closes, focus returns to trigger); test custom components with Enter/Space.
6. **Documentation protocol** — git commit message format; before/after dated screenshots; exporting Axe/WAVE scan results as baseline evidence; accessibility statement template (WCAG 2.1 AA commitment, contact method, last review date).
7. **Quarterly maintenance cadence** — re-scan on every major content or component change; run Axe on new pages before deploy; schedule a full keyboard walkthrough each quarter.
8. **ShipSafe CTA** — scan to confirm template fixes are in the live markup.
