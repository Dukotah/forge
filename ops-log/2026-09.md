**Why ExposureCheck is interesting to launch:**

The tool occupies a distinct, complementary position from LeakCheck (which scans source code pre-commit). ExposureCheck scans the *live deployed* site — the failure mode it catches (deploy-time configuration mistakes) is different from what source code scanners catch. This distinction is technically interesting for Show HN and useful framing for Product Hunt and the subreddit audiences.

Key technically honest angles in the copy:
- The CORS proxy dependency acknowledged upfront (what it sees, what it doesn't, why it's necessary)
- Paste mode as the zero-network alternative
- Path coverage scope (curated list of high-signal paths vs. comprehensive enumeration — it's the former)
- The .git reconstruction scope (confirms exposure, doesn't reconstruct — that would be attacker behavior)
- API key detection in bundles (named provider patterns vs. entropy; false positive distinction between client-side-safe keys and server-side keys that shouldn't be in the bundle)
