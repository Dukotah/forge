A ~950-word fix-intent remediation guide targeting "WCAG compliance for AI-generated sites" — the reader who just got a scan report on their Lovable, Bolt, or Webflow site and wants to know exactly what to change.

**The 5 fixes covered (all genuinely useful, with real code examples):**
1. `lang` attribute on `<html>` — WCAG 3.1.1 Level A — with Lovable/Webflow/WordPress-specific steps
2. Label every form input — WCAG 4.1.2 Level A — `for`/`id` and `aria-label` patterns; why placeholder ≠ label
3. Image alt text — WCAG 1.1.1 Level A — informative vs. decorative, what bad alt looks like
4. Color contrast — WCAG 1.4.3 Level AA — 4.5:1 ratio, how to check in Chrome DevTools
5. Skip-to-main link — WCAG 2.4.1 Level A — full HTML + CSS snippet with focus-visible pattern

Also: ComplyKit callout (CCPA often bundled in ADA demand letters), ShipSafe verify CTA, FAQ JSON-LD schema (6 questions), suite cross-links to ComplyKit / LeakCheck / HardenCheck / ExposureCheck.
